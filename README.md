# udemy-clone
A simple Udemy-inspired website created using HTML and CSS as part of my Full Stack Development learning. The website is designed based on the Udemy platform with online images and links to the real Udemy website

## Features

* Responsive navigation bar
* Search bar
* Course categories
* Online learning banner
* Recommended courses
* Popular courses
* Clickable course images
* Responsive design
* Footer section

## Technologies Used

* HTML5
* CSS3
* Google Fonts
* Font Awesome
* Online images

## Description

I created this project to practice **HTML structure, CSS styling, Flexbox, responsive design, and linking external websites**.

The course images and buttons are clickable and redirect to the **official Udemy website** for demonstration purposes.

This is a personal learning project inspired by the design and concept of an online learning platform. It does not use Udemy's original source code or assets.
